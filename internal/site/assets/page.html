Save this as .github/workflows/chickadee.yml and push a commit. Only enabled labels are listed.

name: Chickadee check
on: [push, workflow_dispatch]
permissions:
  contents: read
jobs:
  check:
    runs-on: {{index .EnabledQueues 0}}
    steps:
      - name: Verify runner
        run: |
          cat /etc/os-release
          nproc
          free -h

A minimal workflow

name: build
on: [push]
jobs:
  build:
    runs-on: chickadee
    steps:
      - run: uname -a

New accounts start with chickadee. Request additional queues before using an explicit label to pin the OS and size. Runners execute one job and are destroyed afterward. Images include a versioned developer-tool baseline. Workflows can install additional tools they need.

Open by design

The controller, image builders and this website live in one public repository. Self-host on your own Linux machine, with local storage and no Kubernetes or external database.

Our hosted deployment is separate from the public core. The prototype is intended for trusted workflows; hostile shared-tenant isolation is still being developed.
